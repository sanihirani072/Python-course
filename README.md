One reel every day (1 to 2 minutes), plus theory notes and practice questions here on GitHub.

Made for **college students** and anyone building a **new skill**.

## 📂 How Each Day Folder Works

- `theory.md`: short notes and examples
- `practice-questions.md`: questions to try on your own
- `answers.md`: check your work after you try
- `solutions/`: runnable Python files

## 🚀 How to Use

1. Watch the day's reel.
2. Read `theory.md`.
3. Solve `practice-questions.md` without looking at the answers.
4. Check `answers.md`.
5. Comment **DONE** on the reel.
